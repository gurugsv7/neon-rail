## Audio

Sound effects are synthesised at runtime with the Web Audio API — no samples.

The three music tracks (`assets/meridian-run-*.mp3`) are royalty-free and
licensed for this use by the project author.

> **Maintainer note:** replace this line with the actual source and licence of
> the three tracks before publishing — for example "*Track Name* by Artist,
> from Pixabay, Pixabay Content Licence". Attribution is cheap and it protects
> the project. If the source turns out not to be clearly licensed, delete the
> three files and the game falls back to its synthesised soundtrack with no
> code changes.

All three were normalised at build time to −18 LUFS integrated with a −1.5 dBTP
ceiling (EBU R128, two-pass) so they sit consistently under the gameplay cues.

## Typefaces

Nothing is bundled and no webfont is fetched — the interface uses whatever the
operating system already has, in this order:

- **Display** — Bahnschrift (Windows; it is DIN 1451, the German railway
  signage face), then DIN Alternate (macOS), then Arial Narrow.
- **Data** — Cascadia Mono, SF Mono, Consolas, then any monospace.

## A note on the runtime

Once loaded, the game makes no network requests at all — no fonts, no CDNs, no
analytics, no telemetry. Camera frames are processed entirely on your device
and never leave it.
